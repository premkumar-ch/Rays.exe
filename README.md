# C++ Ray Tracer

A simple CPU-based ray tracer built from scratch in C++.

It supports:

* Ray-sphere intersections
* Ambient, point, and directional lighting
* Shadows
* Recursive reflections
* PPM image output

No graphics libraries — just C++, math, and a bunch of rays. ✨
