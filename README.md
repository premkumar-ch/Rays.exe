# CPU Ray Tracer

A simple CPU-based ray tracer written in C++ and SDL3.

This project is being developed incrementally to explore the fundamentals of 3D rendering and graphics programming.

## Features

* Ray-sphere intersection
* Ambient, point, and directional lighting
* Hard shadows
* Recursive reflections
* Interactive camera movement
* Mouse-controlled camera rotation
* SDL3 window and rendering

## Controls

* `W` / `S` — Move forward / backward
* `A` / `D` — Move left / right
* `Mouse` — Look around
